# PRD - Sistema de Portaria com Rastreamento GPS

## Objetivo
Desenvolver uma interface de alta fidelidade para um sistema de gestão de portaria de condomínios, focado em segurança, rastreamento em tempo real via GPS e facilidade de uso para diferentes perfis (Admin, Síndico, Portaria e Morador).

## Estilo Visual
- **Tema:** Dark Mode (Fundo escuro profundo com contrastes sutis).
- **Estética:** Moderna, clean, leve e agradável.
- **Cores Sugeridas:**
  - Background: #0F172A (Slate 900)
  - Surface: #1E293B (Slate 800)
  - Primary: #3B82F6 (Blue 500) para ações.
  - Success: #10B981 (Emerald 500) para visitas ativas.
  - Alert: #F59E0B (Amber 500) ou #EF4444 (Red 500) para avisos de segurança.

## Lista de Telas a serem Geradas
1. **Login:** Acesso seguro.
2. **Dashboard:** Resumo operacional.
3. **Gestão de Condomínios:** Listagem e CRUD.
4. **Blocos e Unidades:** Estrutura física.
5. **Moradores:** Gestão de usuários residentes.
6. **Visitantes:** Base de dados de visitantes.
7. **Autorização:** Fluxo de aprovação do morador.
8. **Tela da Portaria:** Check-in/Check-out operacional.
9. **Rastreamento:** Mapa em tempo real.
10. **Alertas:** Central de notificações de segurança.
11. **Dispositivos GPS:** Gestão do hardware.
12. **Auditoria:** Logs do sistema.
13. **Perfil:** Configurações do usuário.
14. **Navegação/Menu:** Estrutura de navegação (Shell).
