# Historico de Releases

Este diretorio centraliza os registros de release do projeto AppCondominio.

## Convencao de nomes

Padrao recomendado para arquivos de release:

- `YYYY-MM-DD-release-rX.md`

Exemplos:

- `2026-04-16-release-r0.md`
- `2026-05-03-release-r1.md`

## Ordem de manutencao

- Releases mais recentes no topo da lista.
- Cada release deve seguir o template em `docs/Template-Release-Notes.md`.

## Lista de releases

1. [2026-04-16-release-r0.md](2026-04-16-release-r0.md) - Baseline de padronizacao documental e operacional.

## Checklist de governanca

Antes de publicar uma release, validar:

- [ ] Checklist de deploy preenchido em `docs/Checklist-Release-Deploy.md`.
- [ ] Release notes revisado por ao menos um mantenedor.
- [ ] Commit SHA e branch registrados no arquivo da release.
- [ ] Evidencias de validacao anexadas.
